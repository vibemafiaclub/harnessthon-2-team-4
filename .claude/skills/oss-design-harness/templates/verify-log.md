# 검증 이력

## 쓰는 규칙

- **화면 단위로 센다.** 같은 화면을 다시 검증할 때마다 그 화면의 행을 늘린다.
- C단계 실패는 **반드시 진단 분류**(국소결함 / 방향오류 / 결정충돌 / 반복실패)를 남긴다. 분류 없이 다시 만들지 않는다.
- **재시도 상한: 같은 화면 C단계 3회.** 3회째 실패면 자동으로 계속하지 말고 사람에게 보고한다 — 무엇을 3번 시도했고 왜 계속 실패했는지 이 표를 그대로 요약해서.
- 재검 전에 이 파일을 **먼저 읽는다.** 같은 문제를 처음부터 다시 진단하지 않기 위해서다.

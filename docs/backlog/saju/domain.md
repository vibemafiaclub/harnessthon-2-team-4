# 사주 풀이 앱 — 도메인 메모 (리허설용)

> 상태: **제품 요구 미확정.** 이 문서는 하네스가 두 번째 도메인에서도 굴러가는지 확인하기 위한 후보 정의다. 여기 적힌 상태·흐름·입력 정책은 승격된 판단기준이 아니다. 실제 제작(build) 전에 사람이 PRD·target·기준을 확정해야 한다.

## 개념 (후보)

| 개념 | 뜻 | 미정 |
|---|---|---|
| 프로필 | 풀이 대상의 출생 정보 묶음 (생년월일·시각·달력 종류·출생지) | 타인 프로필 허용 여부, 궁합 |
| 풀이 요청 | 프로필 1개에 대한 풀이 생성 요청 | 유료/무료, 재요청 정책 |
| 풀이 결과 | 요청에 대한 텍스트·구조화 결과 | 표현 수준(단정/조건부), 용어 설명 깊이 |

## 상태 enum (후보 — 승격 전)

| 코드 | 라벨 | 뜻 |
|---|---|---|
| `draft` | 입력 중 | 필수 입력 미완 |
| `ready` | 확인 대기 | 입력 완료, 사용자 확인 전 |
| `requested` | 풀이 중 | 요청 보냄, 결과 대기 |
| `done` | 결과 준비 | 결과 열람 가능 |
| `failed` | 실패 | 요청 실패, 재시도 필요 |

## 핵심 흐름 (후보)

출생 정보 입력 → 입력 확인 → 풀이 요청 → 결과 읽기. 결제·궁합·오늘의 운세·저장·공유는 **자동 추가하지 않는다.**

## 까다로운 경우 (후보) — 하네스 V-2가 추적할 대상

| 경우 | 어디서 다뤄야 하나 |
|---|---|
| 출생 시각을 모른다 | 입력 화면: "모름" 선택 + 결과 화면: 시각 미상 시 달라지는 부분 표시 |
| 입력을 수정했다 | 기존 결과를 어떻게 표시할지 (무효화 / 버전 병기) — **도메인 결정, 미정** |
| 요청이 실패했다 | `failed` 상태 화면 + 재시도 |
| 풀이가 길다 | 결과 화면의 섹션 분할·요약 |
| 음력/윤달 입력 | 달력 종류 전환, 윤달 표기 — 수집 여부 미정 |

## 콘텐츠 정책 (미정 — 차단 결정)

- 단정적 표현("반드시", "절대") 허용 범위
- 의료·법률·금전 조언으로 읽힐 표현의 처리
- 용어(천간·지지 등) 설명을 본문에 넣을지 툴팁으로 뺄지

## 이 프로젝트가 invitation-scheduler에서 상속하지 않는 것

색 토큰 값, 상태 enum, 화면 이름, 더미 인명, 하단 탭 구성. **상속하는 것**: 절차(0/B/제작/A/C/V), 토큰 선정 절차(값 아님), 네이밍 규칙의 형식(`S<nn> <이름>`, `<Category>/<Name>`, kebab-case), 텍스트 스타일 계층 개수는 프로젝트가 정한다.

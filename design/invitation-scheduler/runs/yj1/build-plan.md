# 제작 계획 — 청첩장모임 스케줄러

- **프레임 규격**: 모바일 390×844 (iOS 기준, `brief.md` 가정 로그)
- **디자인시스템**: 없음(greenfield) → 로컬 미니 DS를 직접 등록. 절차는 `figma-playbook.md` 참고

## 제작 순서

1. 파일 생성 + 페이지 구성 (390×844 모바일 프레임)
2. 토큰 등록 — `brief.md`의 컬러 9종, Spacing 변수, 텍스트 스타일 4종
3. 로컬 컴포넌트
   - 상태 배지 (대기중 / 확정앞둠 / 확정됨 / 완료)
   - 아바타 + 이니셜
   - 모임 카드 (저밀도 압축형 — `decisions.md` 축 2)
   - 지인 리스트 아이템 (색상 도트 + 텍스트 병기 — 축 3)
   - 하단 탭바
4. 화면 1 — 홈 (상태별 모임 리스트 — `decisions.md` 축 1)
5. 화면 2 — 지인 풀 관리 (리스트 + 추가)
6. 화면 3 — 모임 편성 (지인 다중 선택 → 모임 생성)
7. 화면 4 — 모임 상세 (일정 후보 제시 + 회신 수합 현황)
8. 화면 5 — 전체 일정 조망 (캘린더 탭, 겹침 표시)
9. 엣지케이스 — 빈 상태(모임 없음), 회신 마감 임박 배지

각 단계 후 스크린샷으로 즉시 확인하고, 문제가 있으면 다음 단계로 넘어가기 전에 고친다.
